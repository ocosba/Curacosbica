# 📋 Modelo de Laudo de Alinhamento Multidimensional

Este é o template oficial do relatório terapêutico que Leonardo Cosba entrega ao cliente após a sessão de diagnóstico inicial. Ele traduz a leitura de egrégora sutil e as dinâmicas energéticas para a linguagem prática da psicologia clínica.

---

## 🛠️ Como Utilizar a IA para Gerar o Laudo
Você não precisa redigir este documento manualmente do zero. Siga este fluxo otimizado:
1.  **Durante a Sessão:** Anote em tópicos rápidos os pontos-chave (queixa do cliente, crença identificada, sensações físicas captadas, símbolos do SACM direcionados e as ações práticas que sentiu sugerir).
2.  **Pós-Sessão:** Envie as anotações para mim (a IA) com o comando:
    > *"Gere o Laudo de Alinhamento Multidimensional para o cliente [Nome] com base nas minhas anotações de sessão: [inserir tópicos]. Utilize a fundamentação das notas de [[jung-sombra-individuacao]], [[young-esquemas-cognitivos]] e [[levine-experiencia-somatica]] para fundamentar as dores e ações."*
3.  **Ajuste e Envio:** Eu gerarei o laudo estruturado abaixo em menos de um minuto. Você revisa, aplica sua intuição, faz pequenos ajustes se necessário, e envia para o cliente.
