# Pasta workflows: as receitas das suas tarefas

Esta é parte da camada de Capacidades. Aqui ficam os fluxos, que são as receitas das suas tarefas, escritas em linguagem simples.

Um fluxo é um passo a passo que o sistema segue para fazer uma tarefa sempre do mesmo jeito, com consistência. Por exemplo, o fluxo de pesquisa de nicho diz ao sistema como investigar o seu mercado direito.

No começo esta pasta tem só uns poucos fluxos. Ela vai se enchendo naturalmente conforme você avança na trilha e descobre tarefas que se repetem. Cada tarefa que vira fluxo é uma coisa a menos que você precisa explicar de novo.
