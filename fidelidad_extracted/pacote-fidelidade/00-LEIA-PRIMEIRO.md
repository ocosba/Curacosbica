# 📦 Pacote de fidelidade — Cura Arcturiana (SACM)

Tudo que o Antigravity precisa para recriar este projeto com fidelidade **e** aprender o padrão para projetos futuros.

---

## Como usar (ordem sugerida)
1. **Leia `03-metodo-design.md` primeiro** — são as regras gerais do estilo. Valem para qualquer projeto deste autor.
2. **`05-design-system.md` / o prompt** — tokens, tipografia, animações, padrões de componente.
   (O prompt completo e copiável também está no arquivo `Handoff Antigravity` do projeto.)
3. **`01-copy-verbatim.md`** — todo o texto final, palavra por palavra. **Não parafrasear.**
4. **`02-spec-interacoes.md`** — comportamento em JS: canvas de partículas, carrossel arrastável, reveal on scroll, hover, breakpoint, easing.
5. **`04-dados-contato-seo.md`** — WhatsApp, Instagram, meta tags, JSON-LD, disclaimer.
6. **`simbolos/`** — 21 SVGs exatos (pilares, ícones de seção, marca COSBA, 4 mandalas animadas) + galeria `index.html`. Use estes arquivos, não redesenhe.
7. **`assets/`** — imagens reais (retrato do Leo, favicon, fotos de depoimento).

## Referência visual
A versão ao vivo (URL enviada à parte) é a **fonte de verdade visual**. Compare seção a seção com ela enquanto constrói.

---

## Resumo de 30 segundos
- **Tese:** "A espiritualidade trabalha através de você. Não por você." Auto-responsabilidade ativa, mentor firme.
- **Clima:** místico-cósmico, escuro (índigo) com dourado.
- **Stack alvo:** HTML/CSS/JS puro, mobile-first, uma página.
- **Tokens:** `--c-bg0 #0b0826`, `--c-gold #E3BE45`, `--c-violet #C3B8EC`, `--c-orchid #B06CB0` (lista completa no design system).
- **Fontes:** Poppins (títulos), Spectral (corpo), Chakra Petch (rótulos).
- **Não fazer:** emoji, gradientes berrantes, lorem ipsum, parafrasear a copy.
